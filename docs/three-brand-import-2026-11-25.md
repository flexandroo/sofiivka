# Valrom, General Fittings і Tervix: імпорт каталогу

Стан: підготовлено та перевірено локально; віддалену публікацію ще не виконано.

Користувач доручив зібрати весь відповідний асортимент трьох брендів і одразу опублікувати перевірені товари. Для цього релізу окремий перегляд прикладів і ручна публікація чернеток замінені автоматичною перевіркою та керованою публікацією. Решта правил `docs/product-import-standard.md` збережена.

Офіційні джерела: [VALROM Україна](https://www.valrom.com.ua/), [VALROM Industrie](https://produse.valrom.ro/), [General Fittings](https://www.generalfittings.it/), [Tervix](https://tervix.ua/). Правильні назви General Fittings і Tervix підтверджено за офіційними каталогами.

Valrom: 574 позиції з українського асортименту, доповнені 3041 відповідною поточною позицією міжнародного каталогу. Виключені сторонні бренди, водопровідні/газові вироби, зварювальне обладнання та інші позиції поза запитом. 60 позицій не пройшли вимогу підтверджених зображень; вони перелічені у coverage-звіті, серед них українські CAP1/4LE `48600000004П` і JDK40 `48710000404`.

General Fittings: перевірено 28 сімейств і 574 товарні форми. 3658 офіційних рядків мінус 88 вилучених/поза запитом і 46 повторів дають 3524 унікальні артикули. Виробник не надав гривневих цін; іноземні суми не видаються за гривні.

Tervix: 56 із 57 позицій, знайдених у відповідних розділах. Артикул `401112` виключений через відсутність фото й технічних даних виробника. `401211` постачається тільки у складі комплектів, тому ціна порожня, умова вказана в описі. Суперечливі PN16/PN25 у `201164` і `201165` не переносилися. Додаткові подробиці — `docs/tervix-import-2026-11-25.md`.

## Дані та медіа

- 3602 унікальні використані фото WebP, довга сторона не більше 1600 px; лише реальні зображення виробників і підтверджені технічні ілюстрації.
- 115 унікальних використаних PDF, перевірені як PDF. Документи без підтвердження моделі не підставлялися.
- Українські назви, власні описи з технічних фактів, повні очищені характеристики, SEO, джерело та справжній артикул.
- 13 додаткових категорій у чинних розділах водопостачання й каналізації та 3 числові визначення: зовнішній діаметр, довжина труби, кут.
- Новий бренд Tervix із офіційним логотипом; відсутній логотип General Fittings заповнюється офіційним SVG.
- Серії прив'язуються окремим контрольованим кроком. Source evidence, валюту, ПДВ, related і EAN зберігаємо в приватному provenance, не замінюючи характеристики й не вигадуючи типи сумісності.

## Захист ідентичності та даних

Старий імпортер зводив шість артикулів Valrom із суфіксами `П`/`ПБК` до трьох однакових legacy ID. `scripts/import/product-identity.mjs` зберігає колишнє відображення безпечних ASCII-ідентифікаторів, а для нових ідентифікаторів із втратою символів додає детермінований SHA-256 суфікс. Оригінальні SKU і source ID зберігаються. Наявні товари визначаються до генерації нового ID і не змінюються.

У публічних URL медіа нормалізуються роздільники шляхів Windows. Локальні тести імпорту перевіряють цей випадок.

`prepare-brand-release.mjs` відхиляє колізії ID, SKU і назв, ділить SQL за розміром і створює маніфест із SHA-256. Вставка, доповнення серій/provenance і публікація кожної частини виконуються однією транзакцією лише після готовності медіа на production. Guard перевіряє точний import-run `source_ref`; ручні зміни або чужі товари спричиняють відмову, а не перезаписування.

Вихідний контрольний стан PROD: 4233 канонічні товари, 4127 публічних. Деталі захищених полів і контрольна сума — `imports/pre-import-prod-baseline.json`.

## Відтворення та перевірки

Колектори: `scripts/import/valrom-{collect,batch,audit}.py`, `scripts/import/general-fittings-{catalog,editorial,batch}.mjs`, `scripts/import/tervix-{batch,verify}.mjs`. Пакети для збору встановлюються у службові `tmp`, залежності сайту не змінено. Сирі дані, партії, SQL і звіти зберігаються в ігнорованому `imports/`.

```powershell
node scripts/import/three-brand-metadata.mjs
node scripts/import/prepare-brand-release.mjs imports/valrom-2026-11-25.json imports/general-fittings-2026-11-25.json imports/tervix-2026-11-25.json --reference=imports/reference-staged.json
node scripts/import/rehearse-brand-release.mjs imports/releases/three-brands-20261125-e64c7f2f06c0/manifest.json
node tests/import-identity-qa.mjs
node tests/db-local/harness.mjs brand-import-metadata-scenarios.mjs
node tests/db-local/harness.mjs brand-release-scenarios.mjs
node tests/db-local/harness.mjs brand-enrichment-scenarios.mjs
node tests/db-local/harness.mjs import-scenarios.mjs
```

Повний прогін 7195 товарів на реальних міграціях PGlite пройшов: 134 частини, усі товари отримали публічні картки, характеристики й ціни збережені, контрольний старий рядок тотожний, повтори не створюють дублів. Найдовша draft-частина — 250 мс, publication-частина — 503 мс; два atomic replay першої частини також пройшли. Жодних hosted-з'єднань у цій перевірці немає.

Production-ціль: Supabase `sofievka-prod` (`fkjarsouuchjiedrrblc`), GitHub `flexandroo/sofiivka:master`, Vercel `sofievka`. Публікація медіа передує товарам; завершальний деплой оновлює sitemap після запису в БД.
