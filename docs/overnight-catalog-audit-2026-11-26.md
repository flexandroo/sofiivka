## Окремий контекст ущільнювального конуса

Для REHAU **11691691001**, **12446161001**, **12446661001** офіційна назва й опис указують **конус 60°**, а не поворот труби 60°. Для двох трійників точний ETIM `Winkel` дає кут відгалуження 90°. Для прямого перехідника загальне angle-поле вилучається; 0°/180° як кут повороту не вгадується. Факт 60° зберігається як **«Кут конуса»**; оригінальні ETIM/назва/опис залишаються без змін.

Це окремий план `imports/overnight-audit/rehau-cone-correction-plan.json`, який не змінює заморожений пакет 510. Всі три SKU з ним не перетинаються. Майбутній збирач також виправлено: назва з конусом не перебиває кут відгалуження, а прямий адаптер не отримує вигаданий кут повороту. AST-тест реальної функції на всіх трьох SKU та звичайних відводах пройшов; заморожені імпортні batches не перегенеровано.

Повне покриття записів не означає незалежної сертифікації кожного речення. Числові збіги в описах — лише пошук однакової фізичної величини в збереженому джерелі, а не доказ однакового призначення параметра. Нерозв’язані числові/варіантні/джерельні випадки з точними ID залишені у приватних `ambiguous-checks.json`, `base-review/*` і `source-reconciliation/*`; технічні факти для них не вигадуються.

## Scope REHAU без інструменту

Усі 7 835 початкових поточних REHAU перевірено; серед 7 639 первинно опублікованих усі мають оригінальну назву, 6 389 — клас ETIM, 7 379 — вихідний опис. Широкий пошук за роллю, назвою та класом дав 166 кандидатів. Після перевірки призначення лише кабель 10013181001 додається до попередніх 266 виключень: **267 загалом**, з них **197 збережених draft** та **70 ніколи не імпортованих**. Після цієї виконаної зміни публічних REHAU — **7 638**, без повторної публікації попередніх виключень.

Постійні зварні фітинги, кріплення, плити, кабельні подовжувачі автоматики й комплекти клапанів із допоміжним знімальним інструментом не виключаються через саме слово «інструмент». Зокрема, комплект кріплення геотермального тягарця 13524301002 лишається системним компонентом. Широкий детектор є відтворюваною перевіркою, а не обіцянкою, що невідомий незбережений текст виробника повністю досліджений.

Відтворення локальної перевірки:

```text
node scripts/audit/catalog-fact-audit.mjs
node scripts/audit/catalog-scope-review.mjs
node scripts/audit/catalog-audit-summary.mjs
node scripts/audit/catalog-fact-qa.mjs
python scripts/audit/rehau-cone-angle-qa.py
python scripts/audit/rehau-max-temperature-qa.py
```

Останні команди не відкривають hosted-з’єднання. Підсумковий машинний звіт — `imports/overnight-audit/review-summary.json`; він прямо відділяє погоджене виправлення, допустиму різницю представлення, контекст виробника та непідтверджений випадок.
