Опалення

Котельня приватного будинку

Для нового будівництва, реконструкції або заміни основного обладнання без втрати контексту всієї системи.

Надіслати план / специфікацію

Основна задача

Забезпечити потрібні режими опалення й гарячої води, узгодивши джерело тепла, циркуляцію, розподіл, автоматику та безпеку.

Склад системи

  • Джерело тепла й контур гарячої води.
  • Насосні групи, колектори та гідравлічне розділення.
  • Контури радіаторів або теплої підлоги.
  • Автоматика, запірна арматура, захист і монтажні компоненти.

Що потрібно для підбору

  1. План і тепловтрати або вихідні дані для розрахунку.
  2. Потрібні температурні режими й кількість контурів.
  3. Сценарій гарячої води, димохід, електроживлення та місце монтажу.
  4. Наявне обладнання, яке потрібно зберегти або інтегрувати.

Водопостачання

Вода для будинку зі свердловини або мережі

Для приватних будинків і невеликих комерційних об’єктів, де важливі стабільний тиск, захист обладнання та якість води.

Надіслати план / специфікацію

Основна задача

Узгодити джерело, насос, автоматику, запас води, стабілізацію тиску й очищення за фактичними вихідними даними.

Склад системи

  • Насос або ввід від мережі.
  • Захист від сухого ходу, автоматика й гідробак.
  • Механічне та цільове очищення за аналізом води.
  • Розподіл до споживачів, запірна арматура й сервісні вузли.

Що потрібно для підбору

  1. Дебіт, статичний і динамічний рівні для свердловини.
  2. Потрібна витрата, тиск і кількість одночасних споживачів.
  3. Результат аналізу води для підбору очищення.
  4. Місце встановлення, електроживлення, каналізація й можливість сервісу.

Клімат

Клімат для кількох зон

Для житлових, офісних і комерційних приміщень із різними режимами використання кімнат.

Надіслати план / специфікацію

Основна задача

Визначити навантаження, кількість зон, розташування блоків, траси, дренаж, керування та доступ для майбутнього сервісу.

Склад системи

  • Зовнішні та внутрішні блоки або інше джерело холоду й тепла.
  • Траси, дренаж, електроживлення та захист.
  • Керування окремими зонами.
  • Монтажні вузли й сервісні доступи.

Що потрібно для підбору

  1. Плани, площі, висоти й призначення приміщень.
  2. Скління, орієнтація, теплоприпливи й кількість людей.
  3. Можливі місця блоків, трас і дренажу.
  4. Режими роботи, вимоги до шуму та керування.
